## 💼 Arquitetura & Projetos de Destaque

<br>

### 🏢 Plataforma SaaS Multi-Tenant (ERP Financeiro B2B)
> **Stack:** Node.js, Express/Nest, PostgreSQL, React, Tailwind CSS

Desenvolvimento autoral de um sistema tático de controladoria SaaS projetado para gerenciar matrizes e múltiplas filiais com total isolamento e segurança.
* **Componentes Core:** Isolamento via Sharding lógico/Schemas (Row-Level Security), Sistema complexo de emissão e controle de JWT focado em RBAC (Role-Based Access Control).
* **Impacto:** Permite às gerências operarem fluxos de caixas e relatórios simultâneos através de um front-end assíncrono e responsivo de altíssima performance.

### 🤖 Motor Cognitivo de IA (Genesis AI)
> **Stack:** Python, Google Gemini (Vertex AI), Webhooks, JSON Models

Iniciativa de pesquisa com algoritmos comportamentais aplicados no backend para NPCs imersivos, emulando consciência continuada e adaptação a estímulos via Discord.
* **Componentes Core:** Implementação rigorosa do Modelo OCC para matriz emocional, árvores de ação (Behavior Trees) lendo JSON local para gerenciar inventários e memórias, e *Activation Engineering* manipulando os outputs das LLMs para evitar alucinações.
* **Impacto:** Integra as decisões lógicas determinísticas via Dijsktra/A* com a magia interativa das IAs generativas de maneira harmoniosa.
